# DSH Frontend

Only reusable DSH-owned capability presentation may live here.

Allowed responsibility is service-owned presentation/controller code tied to a real DSH capability.

Forbidden here:

- deployable app shells;
- route-tree ownership;
- app bootstrap/native bindings;
- `app-client`, `app-partner`, `app-captain`, `app-field`, or `control-panel` mega-containers;
- generic `shared` presentation dumping grounds.

App composition remains under `apps/*`.
