# DSH owner-bound clients

STATUS: IMPLEMENTATION_IN_PROGRESS

The private `@bthwani/dsh` workspace package exports read-only public Store/Offer projections and opt-in private Store operational GET/PATCH clients. Their sole source contract is `services/dsh/contracts/openapi/dsh.openapi.yaml`, including `paths/store-access.yaml`. The private client requires a current Identity bearer per invocation; it never stores credentials, grants Store rights, writes business facts itself, or treats discovery as checkout authorization. Server-side DSH remains the only Store writer. TypeScript validation and an exported client are not evidence of active Merchant/Operator Web/Android UX.

Local isolated tests exercise the running Go DSH owner against PostgreSQL. For a private Store PATCH, an unreachable network, cancelled in-flight request or malformed success response returns `OPERATION_RESULT_UNKNOWN`: the operation **may already be committed**. The caller must retain the **same** `operationId`, read back the canonical Store availability, and reconcile or replay the same operation rather than inventing a new one. No automatic unsafe retry is implemented in the client. A failed GET remains `OWNER_NETWORK_UNAVAILABLE`. When a caller aborts the request because the active Store/account changes, a late but successful GET is rejected as `OWNER_RESPONSE_STALE`; a late PATCH success is conservatively `OPERATION_RESULT_UNKNOWN` and must never be shown as a successful update to the new account. Consumers must abort their prior view's signal on Store/account switches and reconcile any ambiguous write with the original operation key. Android, production, historical Store migration, checkout, full generated OpenAPI client parity and real operator authorization have **not** been established by package typecheck. Only supported scopes may be shown as operational.

Do not fork transport DTOs elsewhere, add another Store writer, copy the donor implementation wholesale, or introduce a client-side business policy interpreter. Generate contract-derived client code at the owner when source implementation is accepted.
