## Arabic, readability and accessible behavior

Arabic is first class. Merchant/Captain retain the Arabic-only RTL baseline and Operator is Arabic/RTL-first unless Product approves language switching. Use genuine RTL, not right-aligned text or manual per-screen reversals. Expo native uses the centrally resolved expo-localization configuration with installed-binary proof; Expo Web uses root HTML language/direction; Operator uses HTML and Ant locale/direction. No independent per-screen RTL manager or forceRTL workaround. Preserve Arabic shaping/Unicode and meaningful Yemen numeric/date/currency formats, mixed Arabic/Latin phone numbers, codes and quantities.

The approved Web target is WCAG 2.2 AA where applicable and WAI-ARIA interaction semantics; native platforms use equivalent accessibility conventions. Verify real keyboard-only reachability, logical reading/focus/tab order, visible/unobscured focus, focus return/traps after dialogs and sheets, scaling/long Arabic text, labels and state announcements, target sizes, contrast, reduced motion and direction-sensitive icons, gestures, transitions/list scrolling. Do not encode important states solely in color/motion. Use licensed fonts only with verified shaping, fallback and rendering on affected platforms. Keep semantic typography, cohesive spacing/radii, restrained surfaces/motion, readable forms/prose and efficient wide data workspaces. Compact/comfortable density exposes the same capabilities; no excessive ornamental gradients/shadows or empty visual containers. Use a coherent semantic icon family and mirror only direction-sensitive icons.

Minimize taps and required fields for registration, catalog entry, checkout, assignment and recovery. Use progressive disclosure, appropriate safe areas/keyboard/gesture/deep-link behavior, explicit primary and contextual actions. Cover all applicable distinct loading, empty, no-result, forbidden, conflict, offline, error, unknown outcome, busy, disabled, selected, validation and recovery states. Keep safe input/context, prevent duplicate submission and report success only after canonical owner readback; explain the next permitted action without exposing transport tokens, raw internal IDs, enum names or versions as user instructions.

For an authorized thumbnail/logo/document inspection, offer on-demand full-image contain-fit review, accessible dismissal, restored focus and load/error recovery with identical media permissions. No broadening case/Order/private Store exposure or second media store. Imagery and competitor references require rights and provenance; no automatic copying.
