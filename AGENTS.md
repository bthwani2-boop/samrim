# Samrim agent law

Current user/task authority controls the work. Before consequential changes, confirm repository, branch, HEAD and worktree. Preserve unrelated changes, secrets and persistent data. Push, merge, release or change external systems only when authorized.

`knowledge.sources.json` pins durable Product/System/Policy/Quality/Experience/Data/Design meaning. Read the pinned owner only when it can change the decision. `REPOSITORY-STRUCTURE.md` owns placement rules.

## Simplify first

Do one bounded discovery sufficient to identify the affected scope, canonical owner, risk and proof. Then implement. Widen only when new evidence can change the repair.

Keep complexity only for a proven current need. Prefer DELETE → DIRECT USE → STANDARD TOOL → EXISTING OWNER → MERGE → SIMPLIFY/REFACTOR → NEW MECHANISM ONLY WHEN REQUIRED.

Do not preserve wrappers, verifiers, compatibility paths, diagnostics, caches, state machines or duplicate ownership merely because they already exist. A small change must remain small.

Preserve required Product behavior, security, authorization, data integrity and operational safety. Give each mutable fact one canonical writer. Complete replacements across callers, configuration, tests and docs, then delete the losing path.

## Development and proof

Use:

`SMALL CHANGE → AFFECTED CHECK → IMPLEMENT → DIRECT PROOF → DONE`

Git identifies changes. Nx selects affected product projects/tasks. `pnpm check` is the local feedback command for uncommitted work. Use runtime/browser/device proof only when the claim requires it. Final candidate and merge assurance belong to CI plus the GitHub ruleset; do not duplicate them locally for reassurance.

Use native failure output first. Repair the highest proven causal root. Do not hide failures, weaken assertions, manufacture business state, reset established credentials or grant permissions merely to make proof pass.

Secrets stay outside the repository. Executable configuration owns mutable runtime details.

## Closure

Review the complete diff, run the smallest fresh proof that can falsify the change, and check for stale references, dead paths, duplicate owners and partial cutovers. Report the exact final HEAD and any material unproven claim. Closure requires no known material defect, gap or unjustified complexity.
