## 7. Git delivery

Immediately deliver each complete, tested, owned foundation via native Git. Standing or specific human Push authority covers only normal fast-forward to the verified authorized unprotected development upstream. Main/protected branches, archive/**, other remotes, new Branch/Worktree/PR, Merge, release and Deploy require separate authority. No force push or history rewriting to displace peers.

1. Verify repository, branch, remote/upstream, protections/rulesets, current remote SHA, actual ownership, index and exact tested paths/blobs. Run applicable tests, secrets, diff and UTF-8 checks. Stage and commit only owned paths, preserving unrelated staged/unstaged work; no blanket add, empty commit, Reset/Rebase/Stash to displace others or unauthorized staged entries.
2. Freeze the full commit SHA. Verify parent, exact committed files/blobs and all outgoing ancestors versus the observed remote, including each one's ownership and publication authority. A moving HEAD is not authorization. Non-fast-forward or unauthorized ancestors block only that Push.
3. Publish `git push <verified-remote> <verified-full-commit-sha>:refs/heads/<verified-upstream-branch>`. Reconcile changed candidate, index, remote or authority before publication. Never force or push a moving symbolic ref.
4. Read back actual remote ref and immutable commit content. Equality establishes exact delivery. For an authorized successor, prove published SHA ancestry and immutable blobs, record actual successor/changed owned paths, invalidate affected current evidence and obtain successor-specific acceptance. Do not claim equality or successor acceptance from historical delivery. Resolve ambiguous effects before retry; preserve peer work and local achievement.
5. Read exact-candidate mandatory CI, security and quality results. Publication is delivery, not acceptance; pending/failed/unavailable/invalidated proof leaves the affected scope open. Continue independently ready work without waiting for unrelated CI or peers. No extra delivery reservation, review or approval gate beyond actual authority and necessary evidence.
