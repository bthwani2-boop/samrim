This Spec Kit adapter routes to the live canonical owners; it is not a second constitution.

## Constitution Check

- [Agent execution law](../../AGENTS.md): scope, authorization, mandatory tools, concurrency, proof, review and delivery.
- [Repository structure](../../REPOSITORY-STRUCTURE.md): placement, ownership and consumer cutover.
- [Governance index](../../governance/README.md): each decision belongs to its named domain owner.
- [Engineering law](../../governance/engineering.md#mandatory-removal-and-clean-refoundation): mandatory whole-file deletion and reconstruction for authorized remediation, no finding-by-finding or line-by-line repair, no executor-created exceptions, protected-state boundaries and whole-scope proof.

Apply these live owners. Resolve conflicts at the canonical owner rather than copying policy into derived specifications. Preserve historical evidence as history.

## Native workflow

Use the installed Specify CLI and relevant existing artifacts as required by AGENTS.md. The none integration provides agent-neutral scaffolding. Create or extend spec, plan and tasks only when useful for an authorized change. Use a no-branch workflow; do not invoke a branch-creating script mode without separate authorization. Template or CLI updates require verified official provenance, reviewed diff and applicable authority.

Specs describe the change, its consumers and evidence. They neither own business decisions nor grant permissions or certify implementation. Acceptance is proven by actual source, contracts, owner data and applicable runtime checks.
